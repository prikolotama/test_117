# CheckU — калькулятор КЗИ для Vercel и Tilda

Отдельная копия проекта для публикации. Дизайн и логика основного проекта сохранены. В родительском проекте папка Vercel исключена из TypeScript/ESLint-проверок, чтобы две копии не мешали друг другу.
Включены исходники, два используемых баннера, логотипы, шрифты и тесты.
Резервных копий, экспортов, пользовательских ответов и секретов в комплекте нет.

## Размещение

1. Создайте репозиторий GitHub (можно приватный).
2. Загрузите **содержимое этой папки** в корень репозитория. Папки `src`, `public` и файл `package.json` должны быть в корне. Не загружайте весь исходный проект.
3. В Vercel выберите Add New → Project, подключите репозиторий.
4. Framework Preset: Next.js. Root Directory: `.`. Node.js: 24.x.
5. Install Command: `npm ci`. Build Command: `npm run build`. Output Directory: по умолчанию Next.js, не `out`.
6. Переменные окружения для текущей демонстрации не нужны. Нажмите Deploy.
7. Откройте production-адрес и `/assessment` в приватном окне браузера. Для посетителей не должно требоваться входа в Vercel. Preview-ссылку с защитой для Tilda не используйте.

Если загрузили саму папку Vercel внутрь репозитория, укажите Root Directory = Vercel.
Для коммерческого использования нужен соответствующий тариф Vercel, бесплатный Hobby предназначен для личных некоммерческих проектов.

## Вставка в Tilda

1. Откройте `tilda/T123.html` и замените `YOUR-PROJECT.vercel.app` на ваш production-домен Vercel.
2. Скопируйте весь файл в блок T123 и **опубликуйте страницу**.
3. По умолчанию сразу открывается анкета `/assessment`. Для полного лендинга замените путь на `/`.
4. Высота iframe автоматически меняется при раскрытии списков и показе результата. При смене вопроса страница прокручивается к началу анкеты. Внешние ссылки на CheckU открываются отдельно.
5. Вставляйте один такой блок на страницу. Не убирайте `referrerpolicy`: он используется для определения адреса родительской страницы.

Код принимает сообщения только от окна калькулятора и его точного домена. Между Tilda и iframe передаются только высота и координаты прокрутки, без ответов и контактов.
Заголовки, запрещающие iframe (`X-Frame-Options: DENY/SAMEORIGIN`, `frame-ancestors 'none'`), добавлять нельзя. После выбора домена Tilda можно ограничить встраивание заголовком CSP `frame-ancestors` на стороне Vercel.

## Что проверить после публикации

- Вход без авторизации в Vercel, загрузку шрифтов и баннеров.
- Все 16 вопросов, изменение ответа, итоговый экран и повторное прохождение.
- Раскрытие списков, переходы к несоответствиям и высоту блока T123.
- Формы и окна на телефоне и компьютере, в том числе при прокрутке длинного результата.
- Восстановление ответов: браузер может ограничивать локальное хранилище во встроенных страницах; сообщения об ошибках сохранения предусмотрены.

## Текущее состояние

Расчёт выполняется в браузере, ответы сохраняются локально. Формы демонстрационные: состояние успеха показывается, но письма и заявки не отправляются. Для реальной отправки нужен отдельный серверный обработчик и почтовая/CRM-интеграция. Пароли и ключи такой интеграции следует хранить только в серверных переменных окружения Vercel.
Формулировки и расчёт остаются демонстрационными и требуют проверки методологом перед официальным использованием.

## Локальный запуск

```sh
npm ci
npm run dev
```

Проверки: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
Не загружайте в GitHub `node_modules`, `.next`, `.env*`, `.vercel`: они исключены в `.gitignore`.
